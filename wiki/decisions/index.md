# Decisions

Recorded rationale — the *why* behind a choice, kept so the reasoning survives even after the context that produced it is gone. Superseded decisions stay, marked, rather than being deleted.

- [Store Knowledge as Markdown in Git](/wiki/decisions/store-knowledge-as-markdown-in-git.md) — This bundle keeps knowledge as plain Markdown with YAML frontmatter in a git repository, rather than in a database or a hosted service.
